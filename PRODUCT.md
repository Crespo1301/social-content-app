# PRODUCT.md

## Product Summary

Social Vault is a private internal-use caption library for storing, finding, filtering, editing, and copying social content quickly across devices.

It exists because drafting in chat and then pasting into Google Docs creates too much friction when moving between laptop and phone.

## Primary User

Carlos / CSolutions, wearing multiple hats:

- founder
- marketer
- content writer
- client manager
- business operator

## Core Jobs

1. store captions for multiple platforms
2. separate personal and business content
3. find posts quickly by keyword, campaign, city, notes, or tags
4. filter by practical posting metadata
5. copy a caption instantly from phone or laptop
6. track whether a post is drafted, posted, reposted, or archived

## MVP Requirements

- searchable post library
- filter controls
- mobile-friendly card layout
- one-tap copy button
- create/edit/delete posts
- Supabase persistence
- simple private auth or protected access
- seeded example posts

## Nice Later

- copy hashtags only
- copy full package
- image preview
- content backlog
- reusable hashtag sets
- posting calendar
- performance tracking

## Product Tone

- lightweight
- clean
- fast
- intentional
- practical
- mobile-first

Not:

- bulky
- overly corporate
- generic SaaS boilerplate
- analytics-heavy before workflow basics are excellent
