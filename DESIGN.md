# DESIGN.md

## Design Intent

The app should feel like a personal tool you actually want to open every day.

The visual direction should be:

- calm
- polished
- high-clarity
- friendly
- modern
- mobile-comfortable

## UI Direction

- soft surfaces
- strong legibility
- rounded cards
- compact but breathable spacing
- obvious filters
- copy button always easy to find
- no cluttered admin-table feel

## UX Priorities

- search first
- filter second
- copy third
- edit/create fast

The user should be able to:

- open the app on phone
- search or filter quickly
- tap one card
- copy caption
- move on

## Layout Pattern

- strong top summary / hero
- sticky search/filter module
- card grid that collapses gracefully on mobile
- bottom-sheet or modal editing that works comfortably on small screens

## Avoid

- dense enterprise dashboard chrome
- oversized analytics
- tiny tap targets
- too many nested panels
- decorative gradients or glass effects that slow the interface down
